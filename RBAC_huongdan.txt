# Hướng dẫn phân quyền RBAC (Role-Based Access Control) trong Laravel

## 1. Cấu trúc bảng cần có
- users: Lưu thông tin user
- roles: Lưu các vai trò (role)
- permissions: Lưu các quyền (permission)
- role_user: Bảng trung gian user - role
- permission_role: Bảng trung gian role - permission

## 2. Seeder tạo dữ liệu mẫu
- Tạo các role, permission, gán permission cho role, gán role cho user

Ví dụ (Seeder):
```php
// Tạo role admin
$adminRole = Role::updateOrCreate([
    'slug' => 'admin',
], [
    'name' => 'Administrator',
]);

// Tạo permission
$viewUser = Permission::updateOrCreate([
    'slug' => 'users.view',
], [
    'name' => 'Xem user',
]);

// Gán permission cho role
$adminRole->permissions()->sync([$viewUser->id]);

// Tạo user admin
$admin = User::updateOrCreate([
    'email' => 'admin@example.com',
], [
    'name' => 'Admin',
    'password' => bcrypt('password'),
]);

// Gán role cho user
$admin->roles()->sync([$adminRole->id]);
```

## 3. Model
- User:
```php
public function roles() {
    return $this->belongsToMany(Role::class, 'role_user');
}
public function hasPermission($permission) {
    return $this->roles()->whereHas('permissions', function($q) use ($permission) {
        $q->where('slug', $permission);
    })->exists();
}
```
- Role:
```php
public function permissions() {
    return $this->belongsToMany(Permission::class, 'permission_role');
}
```

## 4. Policy
Ví dụ UserPolicy:
```php
public function view(User $user) {
    return $user->hasPermission('users.view');
}
```

## 5. Đăng ký Policy
Trong AuthServiceProvider:
```php
protected $policies = [
    User::class => UserPolicy::class,
];
```

## 6. Sử dụng trong Controller
```php
$this->authorize('view', $user);
```

## 7. Sử dụng trong Blade
```blade
@can('view', $user)
    <a href="#">Xem</a>
@endcan
```

## 8. Các lệnh Artisan thường dùng
- Tạo migration:
  php artisan make:migration create_roles_table
- Tạo seeder:
  php artisan make:seeder RoleSeeder
- Chạy migrate:
  php artisan migrate
- Chạy seeder:
  php artisan db:seed --class=RoleSeeder

## 9. Ghi chú
- Đảm bảo user đăng nhập có role phù hợp và role đó có permission cần thiết.
- Có thể mở rộng thêm bảng permission_user nếu muốn gán permission trực tiếp cho user.

# 10. Phân quyền cho các model khác (ví dụ: Product, Post, ...)

## Bước 1: Tạo Policy cho model mới
Ví dụ với model Product:
```
php artisan make:policy ProductPolicy --model=Product
```

## Bước 2: Đăng ký Policy trong AuthServiceProvider
```php
protected $policies = [
    // ...
    App\Models\Product::class => App\Policies\ProductPolicy::class,
];
```

## Bước 3: Định nghĩa các phương thức trong ProductPolicy
```php
public function view(User $user, Product $product)
{
    return $user->hasPermission('products.view');
}
public function create(User $user)
{
    return $user->hasPermission('products.create');
}
// ...
```

## Bước 4: Thêm permission cho resource mới trong seeder
```php
$actions = ['view', 'create', 'update', 'delete'];
foreach ($actions as $action) {
    Permission::updateOrCreate([
        'slug' => 'products.' . $action,
    ], [
        'name' => ucfirst($action) . ' Product',
    ]);
}
```

## Bước 5: Gán permission cho role phù hợp (ví dụ: admin)
```php
$adminRole->permissions()->syncWithoutDetaching($productPermissions->pluck('id'));
```

## Bước 6: Sử dụng trong Controller hoặc Blade
```php
$this->authorize('view', $product);
```
Hoặc trong blade:
```blade
@can('view', $product)
    <a href="#">Xem sản phẩm</a>
@endcan
```

## Lưu ý
- Lặp lại các bước trên cho mỗi model/resource bạn muốn phân quyền.
- Đặt slug permission theo chuẩn: <resource>.<action> (ví dụ: products.view, posts.create, ...)
- Đảm bảo user có role chứa permission tương ứng để thực hiện hành động.
